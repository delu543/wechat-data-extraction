# 微信数据提取项目

通过 Codex 对话，在本机按“聊天名称 + 时间范围 + 内容类型”导出 Mac 微信 4.x 数据。
支持文字、图片、语音、普通文件和部分可验证表情；语音可直接按顺序合并成 MP4。

> 当前版本：`0.2.0-dev.7` 开发预览。它是完整源码与 Codex Skill，不是已经签名、公证的
> 消费级 Mac App。仅限处理本人有权访问的本机数据。

## 最简单的使用方式

### 1. 在 Codex 中打开这个仓库

仓库地址：

```text
https://github.com/delu543/wechat-data-extraction
```

打开仓库后对 Codex 说：

```text
帮我安装并检查“微信数据提取项目”。
```

Codex 会读取根目录的 `AGENTS.md`，先运行只读检查，再调用幂等安装器。安装器会：

- 把完整源码复制到当前用户的私有应用支持目录；
- 安装固定版本、固定哈希的普通运行依赖；
- 构建并验证本地 Swift 辅助程序；
- 安装 `wechat-local-export` 和 `wechat-local-export-setup` 两个 Skill；
- 不使用 root，不进入微信密钥初始化，也不读取聊天内容。

出于安全原因，仅仅打开 GitHub 链接不会静默执行代码。用户发出“安装”或“使用”请求后，
Codex 才会开始安装。依赖下载、macOS 权限和首次账号初始化仍保留明确的用户边界。

### 2. 第一次使用某个微信账号

登录官方 Mac 微信并打开任意聊天，然后显式对 Codex 说：

```text
$wechat-local-export-setup
```

setup 会先做只读诊断。以下动作彼此独立，必须分别获得明确同意：

1. 安装一次性初始化依赖；
2. 正常退出官方微信并捕获当前账号所需的精确数据库密钥；
3. 创建并保留该账号的本机私有解密快照。

普通安装不会自动进入以上流程。每个新微信账号都需要单独初始化一次。
历史账号目录不会显示为可选项；程序只接受当前官方微信进程能够唯一证明的账号绑定，
不会按文件时间、目录顺序或大小猜测账号。

### 3. 日常直接对话

账号初始化完成后，微信通常保持打开即可：

```text
把“示例讨论群”2026 年 7 月 24 日 14:00 到 15:30 的所有语音直接合成 MP4。
```

```text
先扫描“项目讨论群”昨天 9:00 到 18:00 的文字、图片和文件，告诉我各有多少条。
```

```text
归档“家人群”本周一到周三的文字、图片、语音和文件。
```

Codex 会换算绝对时间、精确匹配聊天、在线生成安全快照并验证结果。群名有歧义、账号绑定
不唯一、媒体缺失或数据库状态不受支持时会停止，不会猜测。

## 手动安装

需要 macOS 15 或更高版本、官方 Mac 微信 4.x、标准 CPython 3.9–3.13，以及带 Swift 的
Apple Command Line Tools。

```bash
./scripts/codex_bootstrap.sh doctor
./scripts/codex_bootstrap.sh install
```

安装完成后如果 Codex 没有立即显示新 Skill，请重启 Codex。安装器是幂等的：同一版本和
同一源码重复运行不会覆盖其他 Skill。已有同名但不属于本项目的 Skill 时会安全停止。

卸载对话层：

```bash
./scripts/codex_bootstrap.sh uninstall
```

卸载只移除本项目管理的 Skill 与 `current` 链接，保留运行环境、版本副本、密钥、快照、
任务和导出文件。任何私人数据删除都需要另行确认。

## 能导出什么

| 类型 | 当前能力 |
|---|---|
| 文字/系统消息 | 导出结构化 JSON、JSONL、Markdown 和 HTML |
| 图片 | V1/V2/旧 XOR 解密，WXGF 转 JPEG，选择最高可验证质量 |
| 语音 | 导出 SILK、逐条 M4A，或直接流式合并为 H.264 + AAC MP4 |
| 普通文件 | 仅导出消息元数据能够唯一验证的本机文件 |
| 表情 | 导出可唯一验证的本机明文资源；私有加密格式保留元数据 |
| 视频 | 当前仅导出消息元数据，不导出视频本体 |

微信本机没有保存的附件不能凭消息索引恢复。严格模式下，只要请求的媒体存在缺失、歧义、
损坏或不支持，整个导出就不会发布半成品。

## 实现原理

日常流程不是录屏，也不是逐条播放：

1. 用当前官方微信进程的只读证据绑定唯一账号；
2. 在旧的已验证快照中精确定位聊天；
3. 只协调本次内容类型需要的数据库；
4. 对 SQLite 主库、WAL 和 SHM 做锁定与一致性检查；
5. 仅重放已提交 WAL 帧并验证新快照；
6. 按聊天、绝对时间、消息类型生成不可变扫描计划；
7. 导出前再次校验计划摘要、数据库指纹、消息与媒体绑定；
8. 原子发布归档，失败时不留下伪成功目录。

纯语音 MP4 使用一次流式编码和一次完整解码探测，不再为每条语音反复生成、读取和删除
临时 M4A。完整可读归档仍保留逐条 M4A。

## 隐私和安全

- 本地导出 helper 没有遥测、远程 MCP 或上传接口。
- 默认导出不会把聊天正文写进命令行、日志或 Codex 对话。
- 如果用户主动要求 AI 总结聊天，选中的内容可能按照其 Codex 账号和数据设置进入模型处理
  链路；这与本地文件导出是两个不同动作。
- 普通导出客户端不接收数据库密钥、SQL、token 或 shell 指令。
- 私有目录使用 `0700`，私有文件使用 `0600`。
- 项目没有键盘输入、粘贴、回车或微信发消息接口。
- 数据库直取不需要屏幕录制、辅助功能或麦克风权限。
- Full Disk Access 只能由用户在 macOS 系统设置中授予实际运行 Codex/Terminal 的宿主。

首次初始化的开发版会把验证后的数据库密钥存入当前用户私有文件。正式消费级版本仍需
完成签名、公证、Keychain 迁移和更多干净 Mac 兼容测试。

## 回归测试

安装普通运行依赖后执行：

```bash
./scripts/release_check.sh
```

它会运行：

- 公开仓库隐私/凭据/禁止文件扫描；
- Plugin/Skill 静态验证；
- direct、content、live 和 portable Python 测试；
- 隔离 HOME 中的安装、幂等与安全卸载测试；
- Swift release 构建、核心检查、媒体自检；
- 禁止键盘/粘贴/事件注入符号检查。

GitHub Actions 在 macOS runner 上执行同一套回归。

## 当前边界

- 仅支持本机 macOS；Windows、Linux 和 Codex 云端环境不能读取本地微信。
- 日常在线扫描可保持微信打开；首次账号初始化仍可能要求正常退出微信。
- Intel Mac 是目标支持架构，但需要更多实机回归。
- 当前仓库许可证状态为 `UNLICENSED`，不是正式开源发行；公开代码不等于商用或二次分发
  授权。项目所有者后续需要结合 GPL 运行依赖选择兼容许可证。
- 项目与腾讯、微信、OpenAI 均无官方隶属关系。
